## النتائج التي عولجت

1. **تضارب اختصارات البحث والتركيز المخفي:** كان `Ctrl+K` يفتح لوحة الأوامر ودليل الوحدات معًا، وكان `/` موجودًا في القائمة المكتبية والجوال ودليل الوحدات. أزيلت مستمعات الاختصار الزائدة من دليل الوحدات، وأُبقي `/` للقائمة الظاهرة فقط بعد فحص `getClientRects()`، و`Ctrl+K` للوحة الأوامر.
2. **عدم اتساق البحث:** أصبحت لوحة الأوامر وقائمتا المكتب والجوال ودليل الوحدات تستخدم `normalizeAdminSearch` و`matchesAdminSearch`. التطبيع يدعم NFKC، إزالة الحركات والتطويل، أشكال الألف، التاء المربوطة، والياء المقصورة، مع طي المسافات وحالة الأحرف الإنجليزية. أضيفت اختبارات لهذه الحالات والبحث بالمسار والمجموعة.
3. **تفاوت مسار التنقل:** أضيف `AdminRouteBreadcrumbs` في تخطيط الإدارة ليعرض المسار وفق العناصر المسموح بها لدور المستخدم. أزيلت المسارات اليدوية من صفحات الطوابير واستوديو الفيديو وطلبات الفيديو كي لا يظهر breadcrumb مكرر. لا يعرض المكوّن رابطًا لصفحة محجوبة عن الدور.
4. **ادعاء أمان مضلل في مركز الإصدار:** كانت الواجهة تصف وسم Git بأنه «موثق» وتعرض حالة نجاح قابلة للتفعيل بمعلمات URL، في حين أن مسار الإنشاء يستخدم API ولا يثبت توقيعًا تشفيريًا للوسم. أزيل ادعاء نجاح الرابط، وظهر مانع التوقيع صراحةً، وعُطل الزر.
5. **حماية من استدعاء الإجراء مباشرة:** لم يُكتفِ بتعطيل الزر؛ أُزيلت من Server Action استدعاءات إنشاء الإصدار والكتابة إلى metadata وسجل العملية. الإجراء، بعد فحص الصلاحية وstep-up، يرفض التنفيذ برسالة مانع واضحة. لا ينشئ commit أو tag أو Draft ولا يغيّر وجهة التنزيل.
6. **حوكمة الاختبارات:** أضيف الأمر `pnpm admin:search:check` واختبار عقدي يثبت عدم عودة اختصارات متعارضة أو مسار إصدار غير موقع؛ وأُدرج في بوابتي `verify` و`verify:pr`.

## ما لم يُعدّ خللاً بحد ذاته

لا يُعدّ غياب `Container` أو `dir="rtl"` أو `<h1>` محليًا دليلًا منفردًا على خلل؛ فقد يوفر تخطيط الإدارة أو مكوّن فرعي هذه العناصر. التقييم البصري النهائي يظل بحاجة إلى اختبار متصفح مصادق عليه. جرى حذف المسارات المتقاعدة بدل إبقائها كتحويلات.
